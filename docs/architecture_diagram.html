Offline by design

  • No cloud, no APIs, no internet at runtime — everything runs on the local machine
  • FastAPI backend + React SPA built with Vite, served statically by the backend
  • SQLite database + images under backend/data/ (app.db + images/ + demo/)

CV pipeline (classical)

  • aligner: ORB feature matching + RANSAC homography, phase-correlation fallback
  • normalizer: CLAHE + percentile stretch for lighting-invariant comparison
  • comparator: SSIM (skimage), pixel diff, edge coverage, surrounding-context ring
  • detector: weighted missing score -> present / review / missing, thresholds configurable

Detection flow

  • Reference board registered; the operator names components (rectangular annotations)
  • Up to 3 test images aligned to the reference, compared per named component
  • Results: green OK, red missing, yellow review; download JSON/CSV exports
